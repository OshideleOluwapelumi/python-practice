# Python Practice

A collection of small Python programs I wrote while learning the language. Each one is a command-line program that practises core concepts such as variables, user input, conditionals, loops, and string handling.

## Programs

### Calculators
| File | What it does |
| --- | --- |
| `MINI CALCULATOR.py` | A simple calculator for basic arithmetic |
| `BILL SPLIT CALCULATOR.py` | Splits a bill between a number of people |
| `CGPA calculator.py` | Calculates a CGPA from course grades |

### Games
| File | What it does |
| --- | --- |
| `Guess number.py` | Number guessing game |
| `ROCK, PAPER SCISSORS GAME.py` | Rock paper scissors against the computer |
| `RPG character creator.py` | Creates a role-playing game character |
| `TRAFFIC LIGHT SIM.py` | Simulates a traffic light sequence |

### Text and security
| File | What it does |
| --- | --- |
| `Caesar cipher.py` | Encrypts and decrypts text with a Caesar cipher |
| `Simple Login.py` | A simple login system that checks a username and password |
| `Backward word Changer .py` | Reverses a word |
| `Backwards word converter.py` | Converts text to its backwards form |

### Checkers
| File | What it does |
| --- | --- |
| `Even or Odd checker.py` | Checks whether a number is even or odd |
| `Leap year checker.py` | Checks whether a year is a leap year |
| `Positive, Negative or Zero checker.py` | Classifies a number as positive, negative, or zero |

## How to run

1. Install [Python 3](https://www.python.org/downloads/).
2. Download or clone this repository.
3. Open a terminal in the folder and run a program, for example:

```
python "Guess number.py"
```
